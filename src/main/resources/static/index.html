По приоритету: primary (если выбран) первым, остальные по priority. Round-robin: по кругу среди доступных сейчас (cooldown/лимит пропускаются), primary игнорируется, при ошибке — failover на следующего. Режим хранится в памяти: после рестарта снова берётся gateway.routing из application.yml.

Провайдеры

Ping — это GET {base-url}/models (путь настраивается через ping-path): токены не тратит. Любой ответ 2xx = доступен; 404/405 = доступен, но список моделей провайдер не отдаёт. «неизвестно» значит, что провайдер эти данные не сообщает, мы их не придумываем. «без ключа» — провайдер с api-key-optional: true (Kilo, OVHcloud) работает анонимно: лимиты считаются на IP (Kilo — 200 запросов/час, OVHcloud — 2/мин на модель); задайте KILO_API_KEY / OVH_AI_API_KEY, чтобы их поднять. «пропущен» — не задан обязательный ключ (для Cloudflare — CLOUDFLARE_API_TOKEN и CLOUDFLARE_ACCOUNT_ID).
